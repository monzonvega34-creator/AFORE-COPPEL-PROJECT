# 🏦 AFORE Coppel — Análisis de Inteligencia de Datos
> Análisis exploratorio y visual del desempeño de AFORE Coppel
> frente al sistema de ahorro para el retiro en México


---

## 📌 Descripción
Este proyecto analiza el desempeño de **AFORE Coppel** dentro del 
Sistema de Ahorro para el Retiro (SAR) en México, comparándola contra 
otras AFOREs del sistema a través de indicadores clave como rendimiento 
de SIEFOREs, evolución de cuentas administradas y tendencias de búsqueda.

---

## 🎯 Objetivos
- Comparar el desempeño de AFORE Coppel vs el resto del sistema
- Analizar la evolución histórica de cuentas administradas
- Evaluar el rendimiento por SIEFORE
- Identificar tendencias de interés público mediante Google Trends
- Construir visualizaciones interactivas para comunicar hallazgos

---

## 📊 Análisis Realizados

### 1. 📈 Comparativa vs otras AFOREs
Comparación de indicadores clave de AFORE Coppel contra el sistema:
- Participación de mercado por número de cuentas
- Activos bajo administración
- Posición relativa en el sistema SAR

### 2. 💰 Rendimiento SIEFOREs
Análisis del rendimiento neto por tipo de SIEFORE:
- SIEFORE Básica de Pensiones
- SIEFORE Básica 90-94
- SIEFORE Básica 75-79
- Comparativa de rendimiento vs inflación

### 3. 👥 Evolución de Cuentas Administradas
Seguimiento histórico del crecimiento de:
- Total de cuentas administradas
- Cuentas activas vs inactivas
- Tendencia de captación

### 4. 🔍 Google Trends
Análisis de interés público en AFORE Coppel:
- Tendencias de búsqueda en el tiempo
- Comparativa vs otras AFOREs en buscadores
- Estacionalidad del interés
